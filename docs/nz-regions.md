# Регіони Нової Зеландії

На `nz.referendum.social` гість після статі та вікової групи може вибрати регіон
або пропустити уточнення. Список за абеткою містить 16 регіонів і Chatham Islands —
окрему острівну територію, яка не входить до цих 16 регіонів.
Джерело: [Stats NZ](https://datafinder.stats.govt.nz/layer/120945-regional-council-2025-clipped/).
Коди — суфікси ISO 3166-2:NZ (`AUK`, `WGN`, `CIT` тощо).

Вибір визначає поточний піддомен запиту, незалежно від мови опитування.
На `en.referendum.social` збережено 50 штатів США та DC; на інших піддоменах
додатковий крок не вмикається. Сервер перевіряє код за країною піддомену,
порядок кроків, сесію та IP. Порожній або чужий код не зберігається.
Пропуск не змінює голос і залишає локацію невідомою.

У результатах на NZ доступні лише регіони Нової Зеландії, з яких уже є голоси,
з підписами на зразок `Auckland, New Zealand`. Для гостей використовуються
підтверджені ID, для зареєстрованих — поточний профіль. Той самий довідник
використовує змінна `@voted_regions`.

## Розгортання

Потрібна вже застосована міграція `m261102_000001_unify_poll_votes`.
Перед відкриттям нової форми виконайте:

```sh
php yii migrate --interactive=0
php yii cache/flush-schema db --interactive=0
```

Міграція `m261110_000001_add_nz_vote_regions` знаходить існуючу країну NZ,
додає їй `iso_code=NZ` і зіставляє регіони за кодами та відомими назвами.
Зберігає наявні ID, нормалізує назви регіонів англійською та додає відсутні.
За неоднозначних записів або незнаних регіонів, використаних у профілях/голосах,
зупиняється до зміни схеми. Виправте зіставлення в довіднику перед повторним запуском.

Поле `poll_vote.state_code` розширюється до 16 символів для трилітерних кодів NZ.
Назва поля зберігається для сумісності з чинними SQL-представленнями й формами.
DDL у MySQL не є транзакційним; розширення поля безпечне для повторного запуску,
а заповнення довідника виконується в транзакції. Після міграції перезапустіть
довгоживучі процеси. Відкат із видаленням регіонів або скороченням поля заборонено,
щоб не пошкодити нові голоси. Старі голоси міграція не змінює.
