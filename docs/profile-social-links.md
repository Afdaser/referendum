# Посилання на соцмережі у профілі

У власному профілі на вкладці «Основне» є п'ять необов'язкових полів: Facebook,
LinkedIn, Instagram, Reddit і X.com — як у блоці соцмереж сайту.
У поле вводять лише ім'я акаунта, за потреби з `@`, або
числовий ID для Facebook. Повну адресу вводити не потрібно. Порожнє поле
прибирає відповідну іконку з публічного профілю.
Числовий ID Facebook сайт відкриває через `facebook.com/profile.php?id=…`.

Сайт сам складає адресу на домені відповідної мережі. Він перевіряє лише
формат імені, не звертаючись до соцмережі для перевірки існування акаунта.
Публічні посилання мають `rel="nofollow noopener noreferrer"` і відкриваються
в новій вкладці. Заповнені посилання одночасно стають значеннями `sameAs`
для `Person` усередині `ProfilePage`.

Після розгортання застосуйте міграцію `m261122_000001_add_profile_social_handles`
командою `php yii migrate --interactive=0`, очистіть кеш схеми бази
(`php yii cache/flush-schema db --interactive=0`) і перезапустіть довгоживучі
процеси. Без міграції нові поля профілю недоступні.
