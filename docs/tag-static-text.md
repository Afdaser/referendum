# Статичний текст на сторінці тегів

Цей функціонал дозволяє налаштовувати власний HTML-текст для блоку інформації на сторінці тегу. Текст задається окремо для кожної мови сайту у розділі адмінки **«Статичний текст на тегах»** (`/xadmin/poll/tag-static-text/index`).

Панель розбита на вкладки за підмовами: у кожній вкладці відображаються лише ті мови, для яких існують локалізовані файли перекладів або які прописані в конфігурації (`params['locales']`). Це допомагає зосередитися на реально доступних версіях сайту, не відволікаючись на незаповнені локалі.

## Доступні змінні

У тексті можна використовувати такі змінні – під час відображення вони автоматично замінюються на актуальні дані:

- `@tag` – назва тегу.
- `@countpoll` – кількість активних опитувань з цим тегом.
- `@firstdate` – дата появи першого опитування за тегом.
- `@lastdate` – дата останнього опитування за тегом.
- `@averagecomments` – середня кількість коментарів в одному активному опитуванні.
- `@totalcomments` – сумарна кількість коментарів до активних опитувань.
- `@popularlink` – посилання на найпопулярніше опитування.
- `@popularname` – назва найпопулярнішого опитування без посилання.
- `@popularvotes` – кількість голосів у найпопулярнішому опитуванні.
- `@averagevotes` – середня кількість голосів в опитуваннях за тегом.
- `@ratinglink` – посилання на опитування з найвищим рейтингом.
- `@ratingname` – назва опитування з найвищим рейтингом без посилання.
- `@rating` – рейтинг найкращого опитування.
- `@latestlink` – посилання на останнє за часом опитування.
- `@latestname` – назва останнього опитування без посилання.
- `@latestdate` – дата публікації останнього опитування.
- `@mostcomments` – кількість коментарів у найактивнішому обговоренні.
- `@totalvotes` – сумарна кількість голосів в усіх активних опитуваннях.
- `@mostcommentedlink` – посилання на опитування з найбільшою кількістю коментарів.

Якщо поле для певної мови залишити порожнім, сайт автоматично покаже попередній згенерований текст.

> **Підказка.** Якщо потрібної мови немає у вкладках, переконайтеся, що для неї існує каталог із перекладами в `common/messages/<locale>` або додано відповідну пару в масиві `params['locales']`.

## Збереження та видалення

- Натискання кнопки «Зберегти» зберігає тексти одразу для всіх мов.
- Порожній текст означає, що запис буде вилучено, і для цієї мови знову використовуватиметься стандартний опис.

## Міграція бази даних

Функціонал використовує таблицю `tag_static_text`. Її створює міграція `m20240930_120000_create_table_tag_static_text`. Запустіть її командою:

```bash
php yii migrate/up --migrationPath=@console/migrations
```

Після виконання міграції в адмінці можна одразу вносити тексти.
