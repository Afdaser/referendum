# Статичний текст на сторінці тегів

Цей функціонал дозволяє налаштовувати власний HTML-текст для блоку інформації на сторінці тегу. Текст задається окремо для кожної мови сайту у розділі адмінки **«Статичний текст на тегах»** (`/xadmin/poll/tag-static-text/index`).

Починаючи з жовтня 2024 року тут же можна керувати SEO-параметрами сторінки: заголовком H1, мета-тегом `<title>` та описом. Для них працюють ті самі змінні, що й у статичному тексті, тому не доведеться вручну оновлювати числа чи дати.

Починаючи з оновлення жовтня 2024 року сторінка редагування також містить просту форму для створення FAQ: достатньо заповнити запитання та відповідь, за потреби використовуючи ті самі змінні, що й у головному тексті. На фронтенді блок FAQ виводиться як microdata Schema.org (`FAQPage`), тож пошукові системи одразу розуміють структуру даних.

Сторінка списку показує ті підмови, для яких вже існують перекладені теги або статичний текст, а також усі мови, вказані в конфігурації сайту (`params.langDomains`). Це дозволяє одразу додати статичний текст навіть для мов, де переклад тегів ще не створений. Для редагування потрібно обрати мову зі списку, після чого відкриється окрема сторінка з формою та підказками щодо доступних змінних.

## Доступні змінні

У тексті можна використовувати такі змінні – під час відображення вони автоматично замінюються на актуальні дані:

- `@tag` – назва тегу.
- `@countpoll` – кількість активних опитувань з цим тегом.
- `@firstdate` – дата появи першого опитування за тегом.
- `@lastdate` – дата останнього опитування за тегом.
- `@averagecomments` – середня кількість коментарів в одному активному опитуванні.
- `@totalcomments` – сумарна кількість коментарів до активних опитувань.
- `@popularlink` – посилання на найпопулярніше опитування.
- `@popularname` – назва найпопулярнішого опитування без посилання.
- `@popularvotes` – кількість голосів у найпопулярнішому опитуванні.
- `@averagevotes` – середня кількість голосів в опитуваннях за тегом.
- `@ratinglink` – посилання на опитування з найвищим рейтингом.
- `@ratingname` – назва опитування з найвищим рейтингом без посилання.
- `@rating` – рейтинг найкращого опитування.
- `@latestlink` – посилання на останнє за часом опитування.
- `@latestname` – назва останнього опитування без посилання.
- `@latestdate` – дата публікації останнього опитування.
- `@mostcomments` – кількість коментарів у найактивнішому обговоренні.
- `@totalvotes` – сумарна кількість голосів в усіх активних опитуваннях.
- `@mostcommentedlink` – посилання на опитування з найбільшою кількістю коментарів.
- `@votes90d` – нові голоси за останні 90 днів (авторизовані + гості).
- `@polls90d` – кількість нових активних опитувань за останні 90 днів.
- `@activepoll90d` – найактивніше опитування за останні 90 днів (із посиланням).
- `@page` – номер поточної сторінки пагінації (працює для SEO-шаблонів пагінації).

Якщо поле для певної мови залишити порожнім, сайт автоматично покаже попередній згенерований текст.

## Мета-теги

- **H1 («Заголовок сторінки»)** — виводиться на першій сторінці списку опитувань. Якщо поле порожнє, використовується стандартне англомовне формулювання.
- **H1 для пагінації** — окремий заголовок для сторінок `/tag/{tag}/page/N` (для `N > 1`).
- **Meta title** — потрапляє у `<title>` сторінки й водночас у заголовок вкладки браузера. Порожнє значення означає повернення до типової формули `Останні опитування {tag}...`.
- **Meta description** — відображається у `<meta name="description">`. Якщо не заповнювати, система підставить стандартний опис з кількістю опитувань.
- **Meta title для пагінації** — використовується на сторінках `/tag/{tag}/page/N` (для `N > 1`).
- **Meta description для пагінації** — окремий description для сторінок пагінації тегу.
- Для полів пагінації доступна змінна `@page`, яка автоматично підставляє номер поточної сторінки (включно з `H1 для пагінації`).
- Якщо поля пагінації порожні, фронтенд використовує звичайні `Meta title`/`Meta description`.
- Усі поля підтримують змінні з таблиці вище, тож можна створювати динамічні заголовки й описи на кшталт «@tag — {countpoll} активних опитувань».

## FAQ-блок

- Кожен запис містить пару «питання – відповідь». Щоб видалити пункт, очистіть обидва поля та збережіть сторінку.
- Можна використовувати HTML і змінні з таблиці вище — система підставить актуальні значення перед рендером.
- На сторінці тегу блок позначається як `FAQPage` у microdata: це підвищує шанси отримати розширені сніпети в пошуку.
- Заголовок блоку відображається як «Часті запитання про опитування на тему {tag}» зі заміною `{tag}` на назву тегу, тож переклади треба оновлювати лише через мовні файли.
- Якщо для мови немає жодного заповненого елементу, FAQ просто не відображається.
- На фронтенді запитання поводяться як акордеон: відповідь приховано, доки користувач не натисне на заголовок із зеленим маркером.
- Заголовок FAQ центрується, а зелений індикатор питання збільшено для кращої помітності на мобільних та десктопних екранах.

## Блок «Latest activity in {TAG} polls»

- На першій сторінці тегу додано окремий інформаційний блок з оперативною активністю:
  - `New votes in the last 90 days: {votes_90d}`
  - `New polls added in the last 90 days: {polls_90d}`
  - `Most active poll in the last 90 days: {active_poll_90d}`
- Блок рендериться лише якщо в адмінці заповнено поле шаблону. Якщо поле порожнє — блок не відображається.
- Через адмінку можна перевизначити HTML-структуру блоку у полі **«Шаблон блоку Latest activity»**.
- У шаблоні працюють змінні `@tag`, `@votes90d`, `@polls90d`, `@activepoll90d`.

## Збереження та видалення

- Натискання кнопки «Зберегти» фіксує зміни лише для поточної підмови.
- Порожній текст та всі порожні мета-поля призводять до видалення запису — у такому разі знову використовується стандартний опис і заголовки.

## Міграція бази даних

Функціонал використовує таблиці `tag_static_text` та `tag_static_faq`. Їх створюють міграції `m20240930_120000_create_table_tag_static_text` і `m20241005_120000_create_table_tag_static_faq`. Міграція `m20241010_120500_add_meta_fields_to_tag_static_text` додає поля для H1 та мета-тегів, `m20260305_120000_add_latest_activity_template_to_tag_static_text` — шаблон блоку активності, а `m20260313_120000_add_paginated_meta_fields_for_main_and_tag_pages` — окремі SEO-поля для пагінації, а `m20260313_130000_add_paginated_heading_fields_for_main_and_tag_pages` додає окремий H1 для пагінації. Запустіть їх командою:

```bash
php yii migrate/up --migrationPath=@console/migrations
```

Після виконання міграції в адмінці можна одразу вносити тексти.

## Пошук на сторінці тегу

Щоб користувачі зосереджувалися на добірці опитувань і довідкових блоках (опис + FAQ), на сторінках тегів приховано глобальну форму пошуку, яка з'являється на інших сторінках списків. Цей блок лишився доступним у звичному місці на головній, у пошуку та в особистих добірках — ми прибрали його лише з тегів, де він дублював функціональність і збільшував відстань до результатів.
