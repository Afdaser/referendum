# Області України для гостьових голосів

На `ua.referendum.social` після вибору статі та віку гість може добровільно вибрати
область проживання або пропустити уточнення. Довідник містить 24 області,
Автономну Республіку Крим, а також міста з окремим адміністративним статусом —
Київ і Севастополь. Коди — суфікси ISO 3166-2:UA.

Вибір залежить від піддомену запиту. Сервер перевіряє код, порядок кроків,
сесію та IP. Підтверджений вибір зберігається в `poll_vote` як `country_code=UA`,
`state_code`, `country_id` і `region_id`. Пропуск залишає локацію невідомою.
У фільтрі голосів показуються лише області України, з яких у цьому опитуванні
вже є голоси. Гостьові голоси й поточні профілі зареєстрованих користувачів
використовують спільні ID областей.

## Розгортання

Після розгортання коду застосуйте міграцію та очистіть кеш схеми:

```sh
php yii migrate --interactive=0
php yii cache/flush-schema db --interactive=0
```

Міграція `m261121_000001_add_ua_vote_regions` використовує наявний запис країни
Україна й намагається зберегти ID її областей за кодами та українськими і
російськими назвами. Відсутні записи додає. Якщо країна дублюється, області
неоднозначні або використані в профілях чи голосах ID не вдалося зіставити,
міграція зупиняється без змін: перевірте назви та ID в довіднику й доповніть
зіставлення перед повторним запуском. Видаляти наявні області не потрібно.
Міграція не змінює старі голоси й не відкочується, щоб не втратити прив'язки
нових голосів і профілів. Після міграції перезапустіть довгоживучі процеси.
